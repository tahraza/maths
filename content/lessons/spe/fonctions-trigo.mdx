# Fonctions trigonométriques

## Intuition et analogie

Les fonctions sinus et cosinus modélisent tous les phénomènes périodiques : oscillation d'un pendule, onde sonore, alternance jour/nuit, marées... Leur étude permet de comprendre et prédire ces phénomènes cycliques.

## La fonction cosinus

:::property[Propriétés de cos]
La fonction $f(x) = \cos x$ :
- **Domaine** : $\mathbb{R}$
- **Image** : $[-1, 1]$
- **Périodicité** : $2\pi$-périodique
- **Parité** : paire ($\cos(-x) = \cos x$)
- **Dérivée** : $(\cos x)' = -\sin x$
- **Primitive** : $\int \cos x \, dx = \sin x + C$
:::

:::property[Variations de cos sur $[0, 2\pi]$]
| Intervalle | $[0, \pi]$ | $[\pi, 2\pi]$ |
|------------|-----------|--------------|
| Variation | décroissante | croissante |
| De | 1 à -1 | -1 à 1 |
:::

## La fonction sinus

:::property[Propriétés de sin]
La fonction $f(x) = \sin x$ :
- **Domaine** : $\mathbb{R}$
- **Image** : $[-1, 1]$
- **Périodicité** : $2\pi$-périodique
- **Parité** : impaire ($\sin(-x) = -\sin x$)
- **Dérivée** : $(\sin x)' = \cos x$
- **Primitive** : $\int \sin x \, dx = -\cos x + C$
:::

:::property[Variations de sin sur $[0, 2\pi]$]
| Intervalle | $[0, \frac{\pi}{2}]$ | $[\frac{\pi}{2}, \frac{3\pi}{2}]$ | $[\frac{3\pi}{2}, 2\pi]$ |
|------------|---------------------|----------------------------------|-------------------------|
| Variation | croissante | décroissante | croissante |
:::

## La fonction tangente

:::property[Propriétés de tan]
La fonction $f(x) = \tan x = \frac{\sin x}{\cos x}$ :
- **Domaine** : $\mathbb{R} \setminus \left\{\frac{\pi}{2} + k\pi, k \in \mathbb{Z}\right\}$
- **Image** : $\mathbb{R}$
- **Périodicité** : $\pi$-périodique
- **Parité** : impaire
- **Dérivée** : $(\tan x)' = 1 + \tan^2 x = \frac{1}{\cos^2 x}$
- Sur chaque intervalle $]\frac{-\pi}{2} + k\pi, \frac{\pi}{2} + k\pi[$, tan est strictement croissante
:::

## Fonctions composées

:::property[Dérivées composées]
Pour $u$ dérivable :
- $(\cos u)' = -u' \sin u$
- $(\sin u)' = u' \cos u$
- $(\tan u)' = u' (1 + \tan^2 u) = \frac{u'}{\cos^2 u}$
:::

:::property[Primitives]
$$\int \sin(ax + b) \, dx = -\frac{1}{a}\cos(ax + b) + C$$
$$\int \cos(ax + b) \, dx = \frac{1}{a}\sin(ax + b) + C$$
$$\int \frac{1}{\cos^2 x} \, dx = \tan x + C$$
:::

## Équations trigonométriques

:::method[Résoudre $\cos x = a$]
Si $|a| > 1$ : pas de solution

Si $|a| \leq 1$, soit $\alpha$ tel que $\cos\alpha = a$ (avec $\alpha \in [0, \pi]$) :

$$x = \alpha + 2k\pi \quad \text{ou} \quad x = -\alpha + 2k\pi, \quad k \in \mathbb{Z}$$

Notation compacte : $x = \pm\alpha + 2k\pi$
:::

:::method[Résoudre $\sin x = a$]
Si $|a| > 1$ : pas de solution

Si $|a| \leq 1$, soit $\alpha$ tel que $\sin\alpha = a$ (avec $\alpha \in [-\frac{\pi}{2}, \frac{\pi}{2}]$) :

$$x = \alpha + 2k\pi \quad \text{ou} \quad x = \pi - \alpha + 2k\pi, \quad k \in \mathbb{Z}$$
:::

:::method[Résoudre $\tan x = a$]
Soit $\alpha$ tel que $\tan\alpha = a$ (avec $\alpha \in ]-\frac{\pi}{2}, \frac{\pi}{2}[$) :

$$x = \alpha + k\pi, \quad k \in \mathbb{Z}$$

(Une seule famille de solutions car tan est $\pi$-périodique)
:::

## Fonctions sinusoïdales

:::definition
**Fonction sinusoïdale**

Une fonction de la forme $f(x) = A\cos(\omega x + \varphi)$ ou $f(x) = A\sin(\omega x + \varphi)$ est une **fonction sinusoïdale** avec :
- $A$ : **amplitude** (valeur maximale de $|f|$)
- $\omega$ : **pulsation** (vitesse angulaire)
- $T = \frac{2\pi}{\omega}$ : **période**
- $\varphi$ : **phase à l'origine**
:::

## Exemples résolus

:::example[Etude de fonction]
Étudier $f(x) = \sin x + \cos x$ sur $[0, 2\pi]$.

**Transformation** : $f(x) = \sqrt{2}\sin\left(x + \frac{\pi}{4}\right)$

En effet :
$$\sin x + \cos x = \sqrt{2}\left(\frac{1}{\sqrt{2}}\sin x + \frac{1}{\sqrt{2}}\cos x\right)$$
$$= \sqrt{2}\left(\sin x \cos\frac{\pi}{4} + \cos x \sin\frac{\pi}{4}\right) = \sqrt{2}\sin\left(x + \frac{\pi}{4}\right)$$

- Amplitude : $\sqrt{2}$
- Période : $2\pi$
- Maximum : $\sqrt{2}$ atteint en $x = \frac{\pi}{4}$
- Minimum : $-\sqrt{2}$ atteint en $x = \frac{5\pi}{4}$
:::

:::example[Equation]
Résoudre $2\cos^2 x - \cos x - 1 = 0$ sur $[0, 2\pi]$.

Posons $X = \cos x$. L'équation devient :
$2X^2 - X - 1 = 0$
$(2X + 1)(X - 1) = 0$
$X = -\frac{1}{2}$ ou $X = 1$

**Cas 1** : $\cos x = 1 \Rightarrow x = 0$ ou $x = 2\pi$

**Cas 2** : $\cos x = -\frac{1}{2} \Rightarrow x = \frac{2\pi}{3}$ ou $x = \frac{4\pi}{3}$

**Solutions** : $\{0, \frac{2\pi}{3}, \frac{4\pi}{3}, 2\pi\}$
:::

:::example[Derivee et primitive]
Soit $f(x) = \cos(3x + 1)$.

**Dérivée** : $f'(x) = -3\sin(3x + 1)$

**Primitive** : $F(x) = \frac{1}{3}\sin(3x + 1) + C$
:::

:::example[Inequation]
Résoudre $\sin x \geq \frac{1}{2}$ sur $[0, 2\pi]$.

$\sin x = \frac{1}{2}$ pour $x = \frac{\pi}{6}$ et $x = \frac{5\pi}{6}$

Sur $[0, 2\pi]$, $\sin x \geq \frac{1}{2}$ pour $x \in \left[\frac{\pi}{6}, \frac{5\pi}{6}\right]$
:::

## Erreurs fréquentes

:::warning
**Erreur 1** : Oublier le coefficient dans les composées

$(\sin(3x))' = 3\cos(3x)$, pas $\cos(3x)$

**Erreur 2** : Se tromper dans les primitives

$\int \sin(2x) dx = -\frac{1}{2}\cos(2x) + C$ (attention au signe et au coefficient)

**Erreur 3** : Oublier des solutions dans les équations

$\cos x = a$ donne généralement deux familles de solutions (sauf si $a = \pm 1$)

**Erreur 4** : Confondre période et pulsation

$f(x) = \sin(2x)$ a pour pulsation $\omega = 2$ et période $T = \pi$ (pas $2\pi$)
:::

## Mini-résumé à apprendre

**Dérivées** :
- $(\sin x)' = \cos x$
- $(\cos x)' = -\sin x$
- $(\tan x)' = 1 + \tan^2 x$

**Primitives** :
- $\int \sin x = -\cos x$
- $\int \cos x = \sin x$

**Équations** :
- $\cos x = a$ → $x = \pm\alpha + 2k\pi$
- $\sin x = a$ → $x = \alpha + 2k\pi$ ou $x = \pi - \alpha + 2k\pi$
- $\tan x = a$ → $x = \alpha + k\pi$
